# 拾光阅读窗

适用于 Windows 10/11 的轻量悬浮小说阅读窗。下载并双击 `Booker_Ver2.exe` 即可运行，无需安装 Python。启动前请先退出仍在运行的旧版阅读器。

## 使用

1. 按 **Ctrl+L**，点击输入栏右侧的 **粘贴** 读取剪贴板中的完整章节网址，再按回车。也可以直接手动输入。
2. 拖动顶栏移动窗口；拖动右下角的 **◢** 调整大小。
3. 阅读时按 **空格** 下翻一屏，按 **→ / ←** 切换下一章 / 上一章（网站提供对应链接时）。顶栏的 **‹ / ›** 和 **Alt+← / Alt+→** 也可切换章节。
4. 底栏 **自动开/关** 控制是否持续调整背景色；关掉后颜色固定。点击 **取色** 可随时重新抓取当前位置的背景色。
5. 点击底栏 **排版**，在同一个面板中调整 **字号、行间距、段间距、字间距**；设置会立即生效并自动保存。**Ctrl+- / Ctrl++** 仍可快速调整字号。
6. 点击 **书架** 或按 **Ctrl+B** 查看已读小说，双击条目继续阅读。按住 **Ctrl** 或 **Shift** 可选择多条记录，再点击 **删除记录**；确认后会删除本机保存的书架条目和阅读进度。关闭窗口时自动保存当前章节网址和阅读位置；下次启动会尝试直接续读最近一本。
7. 按 **Esc** 隐藏阅读窗，再按 **Esc** 重新显示；隐藏时会在全局检测 Esc，因此在其他程序中按 Esc 也会唤出阅读窗。右键打开更多选项；按 **Ctrl+Q** 退出。

可试用的公开章节：[维基文库《红楼梦》第一回](https://zh.wikisource.org/zh-hans/%E7%B4%85%E6%A8%93%E5%A4%A2/%E7%AC%AC001%E5%9B%9E)。

## 设计与边界

- 主窗口没有系统边框，默认置顶，可在右键菜单取消置顶。
- 恢复原来的无闪屏取色方式：自动模式约每 2.5 秒从阅读窗正下方的屏幕区域精确取样，按位置调整背景色；取样仅在本机进行，不上传截图。
- 自动背景开启时，Windows 会把阅读窗标记为不参与屏幕捕获。NVIDIA 录屏可能因此被阻止。关闭 **自动背景** 会固定当前颜色并取消该标记；手动 **取色** 会短暂启用该标记，录制时建议不要使用。隐藏阅读窗时也会取消标记，重新显示后恢复自动背景设置。
- 书架优先使用网站提供的书名和书籍链接识别同一本小说，上下章沿用同一条记录。少数不提供书籍信息的网站，直接粘贴不同章节网址可能被视为不同记录；可以在书架中修改显示书名。
- 删除书架记录只清除本机的书架数据和续读进度，不会删除任何网页内容或访问记录。
- 字间距仅影响阅读窗中的显示效果，原始章节文字不会写入额外空格，也不会影响网页内容、书架链接或正文提取。
- 通过获取网页 HTML 并提取正文，省去页面广告、导航等杂项。不执行页面脚本，也不绕过登录、付费或站点访问限制。某些动态页面或反抓取站点可能无法提取；此时可用右键菜单打开原网页。
- 背景匹配只是视觉舒适度设计，不代表医学意义上的护眼效果。阅读时仍建议保持合适亮度和休息间隔。
- 窗口位置、字号、背景设置、书架中的最新章节网址和阅读位置保存在本机 `%LOCALAPPDATA%\ShiguangReader\settings.json`。

## 从源码运行

需要 Python 3.11 或更新版本：

```powershell
python -m pip install -r requirements.txt
python novel_reader.py
```
